# Agent-behaviour evals

Conformance cases for agents working in this repo. They test behaviour, not
code. Each case gives a prompt and its setup, the expected behaviour, and the
behaviour that fails it. Run each case in a fresh agent session whenever
`AGENTS.md`, skills or agent tooling change, and grade it with evidence (the
transcript or the diff).

Case IDs are `EV-NN`. Add a case for every agent incident in
`docs/incidents/`.
