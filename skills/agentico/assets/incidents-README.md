# Incidents

A blameless postmortem for anything that caused harm or nearly did, including
an agent doing something it shouldn't. Name files `YYYY-MM-DD-short-slug.md`
and copy `TEMPLATE.md`. Every incident ends in a guardrail: a rule in
`AGENTS.md`, a test, a check, or an eval case in `docs/evals/`.
