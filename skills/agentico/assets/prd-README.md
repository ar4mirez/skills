# Product requirement documents

Two kinds of file live here:

- **Area files** (`<area>.md`). These are split out of `PRODUCT.md` when it
  passes its size cap. Each keeps the area's ID prefix and has a row in the
  `PRODUCT.md` Areas table.
- **Source PRDs** from stakeholders, kept as received. When one arrives,
  reconcile `PRODUCT.md` with it in the same pull request.
